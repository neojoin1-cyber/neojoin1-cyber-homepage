개인정보처리방침

유한회사 설탕과소금은 학습에 필요한 정보만 사용하고, 이용자가 자신의 정보를 확인하고 삭제할 수 있도록 운영합니다.

시행일 2026년 8월 27일 · 최종 개정 2026년 8월 27일

바로가기수집 항목이용 목적보관과 삭제처리 기반이용자 권리문의

1. 처리하는 개인정보

서비스 이용 과정에서 다음 정보가 계정 유형과 사용 기능에 따라 처리될 수 있습니다.

  • 계정 정보: 이메일, 이름 또는 표시 이름, 닉네임, 사용자 역할
  • 학교 정보: 학교명, 학과, 학년·반, 교육청 또는 소속 정보
  • 학습 정보: 진도, 점수, 오답, 진단·모의고사 결과, 과제·제출·수업 참여 기록
  • 작성·지도 정보: 자기소개서와 면접 답변 초안, 교사 첨삭, 메시지와 알림
  • 기기·앱 정보: 앱 설정, 동기화 상태, 푸시 알림 토큰, 보안과 오류 확인에 필요한 기술 로그

광고를 게재하지 않으며 광고 ID를 수집하거나 개인정보를 판매하지 않습니다.

2. 이용 목적

  • 본인 확인, 계정 유지와 학교·학급 연결
  • 자율학습, 평가, 작성 실습, 기기 간 진도 동기화
  • 교사의 학급 수업 진행과 학생별 지도·첨삭
  • 학습 알림, 서비스 보안, 장애 대응과 품질 개선

3. 보관 기간과 삭제

계정과 학습 정보는 회원 탈퇴 시까지 보관하며, 관계 법령에 별도 보존 의무가 있는 경우에는 해당 기간만 보관합니다. 탈퇴가 완료되면 계정과 연결된 학습·작성·지도 데이터는 복구할 수 없도록 삭제합니다.

오프라인 학습을 위해 기기에 저장된 사용자별 사본은 앱의 계정 삭제, 공용 기기 로그아웃·기기 데이터 정리 또는 앱 삭제로 제거할 수 있습니다.

계정과 데이터를 직접 삭제할 수 있습니다.학생: 계정·기기 → 계정 및 데이터 삭제교사: 계정 메뉴 → 계정 및 데이터 삭제계정 삭제 방법 보기

4. 서비스 제공 기반

인증과 데이터베이스는 Supabase를, 알림 전송은 Google Firebase Cloud Messaging을, 공개 안내 페이지는 GitHub Pages를 이용합니다. 각 처리 과정에는 서비스 제공에 필요한 최소 범위의 정보만 사용합니다.

전송 구간 암호화, 사용자별 접근 통제, 데이터베이스 행 수준 보안과 사용자별 기기 저장 영역을 적용합니다.

5. 아동·청소년 이용

서비스는 주로 중·고등학생과 교사를 위한 교육 서비스입니다. 만 14세 미만 이용자가 학교 또는 보호자의 적법한 절차 없이 가입하도록 의도하지 않습니다.

6. 이용자의 권리

이용자는 자신의 정보 열람·정정·삭제와 처리 정지를 요청할 수 있습니다. 앱의 계정 삭제 기능을 이용하거나 아래 개인정보 보호 연락처로 요청할 수 있으며, 본인 확인 후 처리합니다.
