## 우선 제작할 공개 사진 묶음

1. `1991~2000 무료 정보교육`: 당시 컴퓨터실·전산부 사진을 찾아 학생 얼굴을 비식별 처리한다.
2. `2000~2014 꺼지지 않은 컴퓨터실`: 제작·올림피아드·SW 활동 사진 3~5장을 시간순으로 편집한다.
3. `2009 학생 SW 개발`: EDUSYS 제작 장면과 KBS·MBC 보도 화면을 한 묶음으로 구성한다.
4. `2011~2019 직업교육 확장`: 맞춤반, 비즈쿨, 글로벌현장학습, 도제학교 사진을 사업별 1장씩 선별한다.
5. `2022 이후 다시 현장으로`: 연구회·교육지원·디지털 서비스 제작 장면은 별도 촬영·기록한다.

## 캡션 원칙

- 사람보다 교육의 장면과 학생의 변화가 먼저 보이게 쓴다.
- `전국 최초`, `최고`, `유일`은 공식 자료로 확인된 경우에만 사용한다.
- 방송 화면은 방송사·프로그램·방송일을 확인한 뒤 출처를 병기한다.
- 학생 사진은 공개 동의 여부를 확인할 수 없으면 얼굴을 식별할 수 없게 편집한다.
- 표창과 위촉장은 자랑 목록이 아니라 해당 활동의 사실 근거로만 사용한다.
