QUICK GUIDE
편안하게 검수하는 방법

      
    
        
  1. 담당 자료 확인왼쪽 검수 자료에서 위촉된 원고와 버전을 먼저 확인합니다.
    2. 
        
  2. 문장을 드래그확인할 문장을 마우스나 터치로 선택합니다.
    3. 
        
  3. 도구 선택형광펜, 전문 의견 또는 수정 필요를 선택합니다.
    4. 
        
  4. 자동저장 확인상단에 ‘모든 내용 저장됨’이 보이면 안전하게 저장된 상태입니다.
    5. 
        
  5. 의견 수정·보완오른쪽 전문 검수의견에서 저장한 내용을 다시 열어 최종 제출 전까지 보완합니다.
    6. 
        
  6. 자료별 확인한 자료의 검토를 마치신 뒤 ‘이 자료의 검토를 마쳤습니다’를 눌러 주세요.
    7. 
        
  7. 중간보고와 최종 제출지정일에 1차 중간보고를 제출하고, 전체 검토가 끝나면 최종 검수의견을 제출합니다.
    8.
